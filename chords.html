About chords and Base 0

A chord is a set of tones heard together. Its interval formula describes each tone from the root; inversions change the bass note without changing the chord's pitch classes. Base 0 uses C = 0 through B = 11 and reduces every interval modulo 12, so octave extensions share a pitch-class number.
